# Grid Based Fluid Simulation
A small grid based fluid simulation made in C

## Building
Run:

    cmake --preset default
    cmake --build --preset default

## Running

After building run:

    ./build/bin/simulation

Or for windows:

    ./build/bin/simulation.exe
